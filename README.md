# GiftWise
#### OVERVIEW
With the holidays approaching, it has become increasingly difficult to track and record gifts between your lucky recipients—especially without getting them something they've already gotten from someone else. With GiftWise, you can simplify this process by tracking and managing gifts, creating a budget, collaborate with others to plan and manage events, and create gift ideas for users.

#### HOSTING
To host locally/deploy,
- Clone repository,
- Install necessary gems, with a package manager, i.e., `bundle`
```bash
bundle install
```
- Install `JQuery` and `Tailwind` libraries
```bash
bin/rails pin jquery
bin/rails tailwindcss:install
```
- Host locally from the project root,
```bash
bundle exec rails server -b 0.0.0.0
```
- Or visit the website to view public deployment.
